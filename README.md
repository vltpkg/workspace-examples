# workspace-examples

Example monorepos demonstrating how to publish multiple packages from workspace-based projects.

## Examples

- **[pnpm-workspace](./pnpm-workspace)** — Publishing packages from a pnpm monorepo
- **[npm-workspace](./npm-workspace)** — Publishing packages from an npm workspace

Each example contains multiple packages that can be published independently to a vlt registry.

## Usage

See the README in each workspace example for setup and publishing instructions.
